# NYS SNAP Assistance Hub

This website is a shortcut and resource page helping New Yorkers quickly access official SNAP (Supplemental Nutrition Assistance Program) resources. Users can find links to applications, card replacement info, FAQs, and more—plus let us know what parts of SNAP they need the most help with using our built-in survey.

## Features

- Direct links to NYS/NYC SNAP application, status check, and help pages
- A built-in survey to find out what users need most help with
- Accessible, mobile-friendly design
- No account required, no personal info collected

## Disclaimer

This site is not affiliated with NY State or NYC government. It does not process benefits or store personal information—just provides reliable shortcut links and guides.

## How to Use

Visit the home page, find the resource you need, or submit feedback through the survey at the bottom.
